# 看懂台股

輸入股票代號，把股價、估值、財報、股利和交易警示用白話整理在同一頁。給第一次看股票的人用，但專業投資人看得到的公開數字這裡都保留。

作者：may22

## 檔案

```
tw-stock/
├── index.html           網站本體，CSS 和 JS 都在裡面
├── apps-script/Code.gs  後端：每天抓資料、回答前端查詢、收使用紀錄
└── README.md
```

## 資料怎麼來

- 每日行情、估值、大盤、公司基本資料、交易警示：後端（Apps Script）每天 17 點和 20 點向證交所、櫃買中心抓，存在 Google 試算表。
- 歷史股價、財報、股利：FinMind。FinMind 會擋 Google 的連線位址（後端去抓會拿到 403），所以這部分改由使用者自己的瀏覽器在打開個股頁時直接向 FinMind 要。

想看示範資料：把 `index.html` 裡的 `ENDPOINT` 改成空字串，會顯示三家虛構公司。

## 改後端的時候

1. 把 `apps-script/Code.gs` 整份貼進試算表的 Apps Script，存檔。
2. 「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署。網址不會變。

想確認來源欄位有沒有改版，執行 `testSources` 看執行紀錄。

## 測試到哪裡

- 證交所和櫃買中心共 15 個來源的欄位，已經用 2026-11-17 實際跑出來的 testSources 紀錄核對過。
- 畫面用手機尺寸的瀏覽器開過，前後端也用假資料串過一輪。
- 還沒確認的有兩件：瀏覽器直接抓 FinMind 能不能成功，以及 FinMind 資產負債表的科目名稱（影響股東權益報酬率和負債比）。這兩件要實際打開個股頁才知道，抓不到的區塊會顯示「這次沒抓到」。
- FinMind 沒登入的免費額度有限，一個人短時間查很多檔會暫時查不到歷史資料。

## 和企劃書的差異

企劃書第一版的範圍都做了，除了這幾項：

- 公司主要業務的文字介紹：找不到免費的公開資料來源，目前只列產業別，並在頁面上說明。
- 還原股價開關：沒做。圖上是原始價格，除息日有標記，旁邊有「為什麼看起來像大跌」的解釋。
- 興櫃股票：沒收。
- ETF：查得到，會顯示股價、走勢、配息，但成分股、費用、折溢價要等第二版。

第二版的法人買賣、融資融券、技術指標、重大訊息、比較頁都還沒做。

## 使用紀錄

寫在試算表的 `events` 分頁，只記行為，不記個人資料。事件有 start、search、stock_view、term_open、expand、mode_switch、checklist_click、watchlist_add、fetch_error。
